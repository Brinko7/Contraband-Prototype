# Enemy Sprite Sheet Layout

All sheets are a 4-column x 4-row grid generated by `spritegen/gen_enemies.py`.

- **Columns (0-3) = 4-frame walk cycle.** Frame order: 0 contact, 1 passing
  (body bob up), 2 contact (opposite leg), 3 passing (body bob up).
  A natural loop is `0,1,2,3` repeating.
- **Rows (0-3) = facing direction:**
  - Row 0 = DOWN  (facing the camera / toward the player)
  - Row 1 = LEFT
  - Row 2 = RIGHT
  - Row 3 = UP    (facing away)
- Light is from the UPPER-LEFT; each material uses a 4-5 tone ramp with a hard
  dark outline (`OUTLINE` = near-black violet).

## Humanoid sheets — cell 32w x 40h (sheet 128 x 160)

`region = Rect2(col*32, row*32... )` → use `Rect2(col*32, row*40, 32, 40)`.

| File                         | Cell  | Foot baseline y | Notes |
|------------------------------|-------|-----------------|-------|
| sprites/enemy_guard.png      | 32x40 | 38              | City watch. Steel helm w/ red eye-glint, blue-grey tabard + gold emblem, chainmail, spear. Baseline threat. |
| sprites/enemy_captain.png    | 32x40 | 38              | ~8% larger. Red surcoat, gold pauldrons + brow band, red plume helm, sword. Ornate. |
| sprites/enemy_boss.png       | 32x40 | 39              | ~18% larger feel. Black ornate armor, horned/crowned helm, glowing red eyes, flowing red cape (drawn in LEFT/RIGHT/UP rows), sword. Imposing. |
| sprites/enemy_skeleton.png   | 32x40 | 38              | Bone skull w/ green-glowing hollow sockets, grey tattered cloth, bone limbs, rusty chipped blade. |
| sprites/enemy_goblin.png     | 32x40 | 38              | Small/hunched (~0.78 scale). Green skin, big pointed ears, yellow eyes + fangs, leather scraps, steel dagger. |
| sprites/enemy_gnoll.png      | 32x40 | 38              | Hyena-headed beastman (~1.12 scale). Brown fur, rounded ears, snout + amber eyes, leather, broad iron cleaver. |

Notes:
- Feet rest on/near the baseline y within the cell; align all enemies on this
  baseline when placing in the world (set Sprite2D offset so y=baseline maps to
  the character's ground point).
- The boss cape only renders in the LEFT/RIGHT/UP rows (it would occlude the
  front in DOWN), so DOWN frames show the front armor cleanly.
- Weapons are held on the figure's right side (screen-right in DOWN, leading
  side in profile rows) and animate slightly with the walk cycle.

## Quadruped — sprites/enemy_hound.png — cell 32w x 28h (sheet 128 x 112)

`region = Rect2(col*32, row*28, 32, 28)`.

| Row | Direction | Reads as |
|-----|-----------|----------|
| 0   | DOWN  | Front view, head + two splayed front legs, glowing eyes toward camera. |
| 1   | LEFT  | Side profile, 4-leg running/gallop cycle (legs swing in opposing phase across the 4 frames). |
| 2   | RIGHT | Side profile mirrored, 4-leg running cycle. |
| 3   | UP    | Back view, tail up, hindquarters + ears. |

- Foot baseline y = 25.
- Dark blue-grey fur (rgb ~64,60,72), glowing amber eyes, pointed alert ears,
  pointed snout with dark nose. Side rows are the primary "chase" animation.

## Regenerate

From project root:
```
python3 spritegen/gen_enemies.py
```
Writes the 7 sheets to `sprites/` and 6x checker-backed previews to
`spritegen/previews/`.
