# Player Sprite Sheets — Layout

Generated by `spritegen/gen_player.py` (pure stdlib, imports `spritegen/lib.py`).
Run from the project root: `python3 spritegen/gen_player.py`

## Output files

| File | Contents |
|------|----------|
| `sprites/player_cutpurse.png`     | Cutpurse class sheet |
| `sprites/player_shadowdancer.png` | Shadowdancer class sheet |
| `sprites/player_assassin.png`     | Assassin class sheet |
| `spritegen/previews/player_*.png` | 6x checker-backed previews (inspection only — do NOT ship) |

Each sheet is **128 x 160 px** = a 4 x 4 grid of **32 x 40** cells.

## Grid mapping

- **Rows = facing direction**
  - row 0 = **DOWN / south** (faces camera, hood + face/eyes visible)
  - row 1 = **LEFT / west** (profile)
  - row 2 = **RIGHT / east** (profile; mirror of left)
  - row 3 = **UP / north** (back of hood, no face)
- **Columns = 4-frame walk cycle**
  - col 0 = contact / idle
  - col 1 = left-leg-forward
  - col 2 = passing / idle
  - col 3 = right-leg-forward

Cell `(col, row)` lives at pixel `(col*32, row*32-row*... )` — precisely
`origin_x = col*32`, `origin_y = row*40`.

Frame-rate suggestion: 8–10 fps for the walk; show col 0 (or col 2) when idle.

## Cell geometry (within a 32x40 cell)

| Value | Px | Notes |
|-------|----|-------|
| Horizontal centre (`CX`) | 16 | character is centred on this column |
| Foot baseline (`BASE_Y`) | 36 | boots rest with soles ~here |
| Empty margin at bottom | ~3 px (y 37–39) | leave for drop-shadow / grounding |
| Shoulder line (`top`)    | 15 (–1 on bob frames) | hood crown starts ~10px above |

The foot baseline is held **constant across all 16 frames**; only the head/torso
bob by 1 px on the passing frames (col 1, col 3), so the walk does not visually
hop. To place a sprite in-world, align cell-y 36 to the character's ground point.

## Light & shading (house style)

- Light source: **upper-left**. Highlights on top-left faces, core shadow on the
  bottom-right, thin rim/bounce on the lower-right edge.
- Every silhouette gets a hard dark outline via `Canvas.auto_outline()`.
- Each material uses a 5-tone ramp from `lib.ramp(base, 5)`.

## Per-class notes

| Class | Palette base | Silhouette accents |
|-------|--------------|--------------------|
| **Cutpurse**     | `PAL['leather']` brown, light hood trim | gold buckle + gold hem band, steel dagger in right hand, bare hand on left |
| **Shadowdancer** | `PAL['cloth_purple']` silk, violet trim  | flowing short **cape** that sways behind across frames; faint **violet eye-glow** in the hood |
| **Assassin**     | `PAL['cloth_black']` near-black armor    | **steel pauldrons** on both shoulders, diagonal **red crossbelt**, red hem trim, **red eye-glow** |

All three carry a small dagger in the leading/right hand (visible in down + side
views). Skin tones are nudged per class (tan / pale-violet / dark) for variety.

## Regenerating / editing

Everything is code-generated — there are no source images. Edit
`spritegen/gen_player.py`:
- `THEMES` dict — per-class colours, `cape`, `pauldrons`, `crossbelt` flags.
- `WALK` / `STRIDE` — leg lift and foot spread per frame (the walk cycle).
- `build_down` / `build_side` / `build_up` — per-direction figure construction.

Note: `lib.Sheet.place()` has inverted blit arguments, so this generator uses its
own `place()` helper to composite cells. (lib.py was left unmodified.)
